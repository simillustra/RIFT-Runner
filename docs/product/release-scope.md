# Release Scope
## First playable slice
Offline single-player; three heroes; hybrid traversal; combat; enemies and boss; two modular environments; touch controls; HUD/settings; basic progression; Android test build; iOS project/export validation; automated tests and device performance report.

## Excluded
Mandatory accounts, always-online behavior, live co-op, purchases, remote AI enemy control and runtime AI asset generation.

A feature is in scope only when implemented, tested, documented and accepted. Roadmap intent is not delivery evidence.

# Game Design Document
## Pillars
Momentum/readable traversal; combat agency; distinct hero identities; escalating threats; replayability through modular routes.

## Core loop
Select hero → enter environment → traverse hazards → fight → collect rewards → survive encounter/boss → resolve run → apply progression → replay.

## Heroes
Vanguard: durable defender (Bulwark concept). Phantom: fast evasive assassin (Phase Shift concept). Cipher: balanced tactician (Overclock concept). Current stats/timings are placeholders, not balanced gameplay.

## Environments
Infected City (urban survival) and Alien Facility (science-fiction industrial) are planned fictional settings. Layouts/encounters require separate design.

## Controls/progression
Guided virtual joystick and free-hand gestures are planned. Gesture grammar, accessibility, economy and unlock pacing require playtesting and approval.

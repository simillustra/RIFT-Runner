# User Stories
- As a player, I can start offline without signing in.
- As a player, I can choose Vanguard, Phantom or Cipher.
- As a player, I can understand health and ability status.
- As a player, I can choose a touch-control style.
- As a player, I can traverse, fight and evade responsively.
- As a player, I can earn run rewards and retain basic progression.
- As a player, I can adjust persistent settings.
- As a developer, I can add heroes through data Resources.
- As a developer, I can validate IDs/content before runtime.
- As a developer, I can run headless tests in CI.
- As an operator, I can add optional online/AI adapters without breaking offline play.
Refine each story into task-specific acceptance criteria before implementation.
